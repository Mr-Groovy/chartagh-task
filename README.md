# سیستم تسک چارطاق

پنل داخلی تیم چارطاق برای `task.chartagh…`؛ یک اپ Next.js جدا از سایت اصلی که روی همان هاست، فقط روی ساب‌دامین خودش اجرا می‌شود.

## امکانات

- **ورود جداگانه** برای `SajjadGR` و `Amirhossein` (هر دو مدیر)
- **تسک‌ها** در چهار بخش: کلی، پروژه‌ای، روزانه (هر روز از نو تیک می‌خورد)، به‌زودی؛ با انجام‌دهنده، اولویت، موعد شمسی و تیک
- **تایمر آغاز/پایان کار** در بالای همه‌ی صفحه‌ها و روی میز کار
- **گزارش‌ها**: روزانه (ورود، خروج، تیک‌ها با ساعت)، هفتگی (شنبه تا جمعه) و ماهانه (ماه شمسی) با نمودار
- **پروژه‌ها**: درصد پیشرفت، تسک‌های مانده و انجام‌شده‌ی هر پروژه
- **پنل مدیریت**: جدول همه‌ی تسک‌ها با انتقال گروهی بین پروژه‌ها/افراد/بخش‌ها، مدیریت پروژه‌ها، اصلاح ساعت‌های کاری، تغییر رمز و دانلود پشتیبان
- حالت روز/شب (هم‌کلید با سایت اصلی)، ریسپانسیو با منوی پایین در موبایل

## اجرا روی کامپیوتر

</div>

```bash
npm install
npm run dev
```

<div dir="rtl">

بعد [http://localhost:3001](http://localhost:3001) را باز کنید (سایت اصلی روی ۳۰۰۰ است، این روی ۳۰۰۱).

## رمزها و تنظیمات

فایل `.env.local` (در گیت نیست):

| متغیر | کارش |
|---|---|
| `TASK_PASSWORD_SAJJADGR` / `TASK_PASSWORD_AMIRHOSSEIN` | رمز اولیه؛ فقط بار اولی که `data/db.json` ساخته می‌شود خوانده می‌شود |
| `AUTH_SECRET` | امضای کوکی ورود؛ عوض کردنش همه را خارج می‌کند |
| `DATA_DIR` | (اختیاری) مسیر پوشه‌ی داده؛ پیش‌فرض `./data` |

بعد از اولین ورود، رمزها را از **مدیریت ← کاربران و داده** عوض کنید.

## داده‌ها

همه‌چیز در یک فایل `data/db.json` است (برای دو نفر دیتابیس لازم نیست). هر روز یک نسخه در `data/backups` نگه داشته می‌شود و از پنل مدیریت هم می‌شود پشتیبان دانلود کرد. **پوشه‌ی `data` را هنگام آپلود نسخه‌ی جدید پاک نکنید.**

## انتشار روی ساب‌دامین

۱. در کنترل‌پنل هاست یک ساب‌دامین بسازید: `task.chartagh.ir` (یا دامنه‌ی خودتان) و SSL را فعال کنید.
۲. پوشه‌ی این پروژه را (بدون `node_modules` و `.next`) روی هاست بگذارید، کنار سایت اصلی ولی در پوشه‌ی جدا.
۳. روی سرور:

</div>

```bash
npm install
npm run build
npm run start
```

<div dir="rtl">

۴. **cPanel / DirectAdmin (Setup Node.js App):** یک اپ Node بسازید، Application root را این پوشه، Application URL را ساب‌دامین و startup file را `node_modules/next/dist/bin/next` با آرگومان `start` بگذارید؛ متغیرهای `.env.local` را در بخش Environment variables وارد کنید.
**سرور مجازی (nginx):** اپ را با `pm2 start npm --name chartagh-task -- start` اجرا کنید و ساب‌دامین را به `localhost:3001` پروکسی کنید:

</div>

```nginx
server {
  server_name task.chartagh.ir;
  location / {
    proxy_pass http://127.0.0.1:3001;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

<div dir="rtl">

> سرویس‌های بدون دیسک ماندگار (مثل Vercel) برای این اپ مناسب نیستند، چون داده در فایل ذخیره می‌شود.
